# Security

SI Desk is an unofficial public beta. Only the latest release is supported.

## Reporting a vulnerability

Report a vulnerability in private through GitHub's **Report a vulnerability** (private security advisories). Do not open a public issue for it.

The report will be looked at as soon as possible. There is no promised response time.

## Keys and tokens

Never post API keys, connector tokens, or webhook keys anywhere. That includes issues, pull requests, commits, chat, and screenshots.

If a key gets exposed, rotate it. For the connector token, SI Desk has a **Regenerate** button.
