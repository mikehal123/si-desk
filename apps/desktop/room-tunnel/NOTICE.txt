cloudflared (Cloudflare)
https://github.com/cloudflare/cloudflared

SI Desk uses cloudflared so a shared room can accept an online invitation while the host app stays open.
Release builds download the pinned Windows amd64 binary below and copy it to room-tunnel\cloudflared.exe next to SIDesk.exe.
The git repository does not contain that executable.
